# راهنمای سریع آپلود روی GitHub و Vercel

## ۱. دانلود و extract
فایل ZIP را دانلود و در یک پوشه extract کنید.

## ۲. آپلود روی GitHub

### روش ساده (بدون Git):
1. به GitHub.com بروید و یک repository جدید بسازید
2. روی **uploading an existing file** کلیک کنید
3. تمام فایل‌ها و پوشه‌ها را drag کنید
4. **Commit changes** را بزنید

### روش با Git:
```bash
cd presentation-editor
git init
git branch -M main
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/USERNAME/presentation-editor.git
git push -u origin main
```

## ۳. دیپلوی روی Vercel
1. به vercel.com بروید و با GitHub وارد شوید
2. **Add New → Project** را بزنید
3. repository را انتخاب کنید
4. تنظیمات به‌صورت خودکار تشخیص داده می‌شود
5. **Deploy** را بزنید

## ۴. تمام!
بعد از چند دقیقه سایت شما روی آدرسی مثل:
`https://presentation-editor.vercel.app`
در دسترس خواهد بود.
